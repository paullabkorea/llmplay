Agent가 일하고, 내가 검토해요

Agent는 채팅창 밖으로 나온 AI예요. 내 컴퓨터의 파일을 열고, 도구를 쓰고, 파일을 만들어 저장해요. 그래서 "첨부"가 "모아줘"로, "복사해서 붙여넣기"가 "만들어줘"로 바뀌었어요.

그때와 지금

같은 결과물을 만드는 데 걸리던 시간이 이만큼 달라졌어요

위니브가 겪은 정도를 보여 주는 예시예요. 일과 사람에 따라 다르고, 검토하고 고치는 시간은 여기 들어 있지 않아요.

줄어든 것과 늘어난 것

줄어든 시간

  • 양식을 찾고 여는 시간
  • 지난 파일에서 문장을 옮겨 적는 시간
  • 표와 장표를 다시 그리는 시간

늘어난 시간

  • 무엇을 약속할지 정하는 시간
  • 숫자가 맞는지 확인하는 시간
  • 본질을 다시 생각하는 시간

위니브는 이렇게 말해요. 전처럼 작성에 힘을 들이는 것이 아니라, 검토하고 상상하며 본질에 집중하기 위한 시간에 공을 들인다고요.

압축하면 파일 하나가 되고, 풀면 다시 폴더예요. 안에 든 건 코드가 아니라 사람이 읽을 수 있는 글이에요. 그래서 모델이 바뀌어도, 다른 AI로 옮겨도 그대로 읽혀요.

Skill로 만들까? 세 가지 질문

  1. 다음 달에도 또 하나요?한 번 하고 말 일은 그냥 프롬프트로 하는 게 나아요. 만드는 시간이 아까워요.
  2. 재료만 바뀌고 규칙은 같나요?일수와 인원은 매번 달라도 단가표와 양식이 같다면 Skill의 자리예요.
  3. 나 말고 다른 사람도 하나요?규칙이 내 머릿속에만 있으면 팀원은 못 해요. 휴대폰만 든 나도 못 하고요.

세 가지 중 하나도 걸리지 않으면 Skill을 만들지 않아도 돼요. 로고와 메뉴 사진을 폴더에 넣고 한 번 시키면 끝나는 일도 많아요.

위니브가 실제로 쓰는 Skill 아홉 가지

『에센셜 Claude Skill』 2장에 나오는 목록이에요. 이 중 md-to-hwpx와 public-bid-proposal은 공개되어 있고, 나머지는 회사 정보가 들어 있어 공개하지 않아요.

핵심 개념

시뮬레이션에서 방금 본 것들, 궁금한 개념을 눌러 보세요

AI에게 지금 무슨 일을 하는 중인지 알려 주는 재료예요. 공고문, 제안서, 단가표, 작년 보고서가 전부 맥락이에요. 맥락이 없으면 AI는 그럴듯한 일반론만 써요. 대화의 비밀에서 AI가 맥락을 어떻게 기억하는지 볼 수 있어요.

AI의 시대에는 채팅창에서 묻고 답을 받았어요. Agent는 답 대신 일을 해요. 내 컴퓨터의 파일을 찾고, 열고, 도구를 쓰고, 파일을 만들어 저장해요. 한 번에 끝나지 않으면 찾고, 읽고, 만들고, 되묻는 여러 단계를 스스로 이어요. 그 안에서 다음 단어를 고르는 원리는 단어 맞히기와 같아요.

맥락을 미리 묶어 둔 폴더예요. 설명서(SKILL.md)와 규칙 파일이 들어 있어요. 압축하면 파일 하나가 되고, 풀면 다시 폴더예요. 매번 같은 것을 설명하는 대신 한 번 적어 두는 것, 그게 전부예요. 사람이 읽는 글로 적혀 있어서 모델이 바뀌어도 그대로 읽혀요.

프롬프트는 이번 한 번의 말이고, Skill은 매번 반복되는 규칙이에요. 한 번 할 일에 Skill을 만들면 만드는 시간이 아깝고, 매주 할 일을 프롬프트로만 하면 같은 설명을 매주 다시 해요. 질문이 달라지면 답이 달라지는 원리는 프롬프트의 비밀에 있어요.

Skill 여러 개가 줄줄이 이어지는 것이에요. 공고를 고르고, 제안서를 쓰고, 그 제안서로 견적서와 발표 자료와 카드뉴스를 만들어요. 가운데에 제안서가 있어서, 제안서가 정확하면 나머지도 정확해요. 반대로 제안서가 틀리면 넷이 같이 틀려요.

AI는 다음 단어를 확률로 고르는 기계라서 그럴듯하게 틀릴 수 있어요. 숫자는 특히요. 그래서 사람이 남아요. 무엇을 약속할지 정하고, 숫자가 맞는지 보고, 책임을 지는 일이요. 줄어든 건 만드는 시간이고 늘어난 건 판단하는 시간이에요.

이 페이지에서 파일이 날아가는 모습, 작업 기록, 걸린 시간은 연출이에요. 실제로는 Agent에게 내 컴퓨터 폴더를 열어 주고 채팅으로 말하면 돼요. 어디까지 스스로 하게 둘지(파일 삭제, 메일 보내기 같은 것)는 사람이 정해요. 다만 결과물은 진짜예요. 위니브가 실제 사업에서 이렇게 만든 파일이고, 눌러서 열어 볼 수 있어요.

여기 나온 결과물의 출처
  • 화면 사진 여섯 장은 위니브의 전자책 『에센셜 Claude Skill』 2장 '위니브 일하는 방식'에 실린 공개 샘플이에요. 제안서 35쪽, 견적서, 발표 자료 19장, 발표 대본, 카드뉴스 8장, 사업 탐색 대시보드예요.
  • 원본 파일(PDF, HTML, Excel)은 위 '실제 파일을 열어 보세요'에서 그대로 열 수 있고, 같은 장에 공개 Skill 두 가지(md-to-hwpx, public-bid-proposal)도 올라와 있어요.
  • 사업명 '제주 AX 대전환 인재양성 프로그램 운영(가칭)'은 책에 실린 샘플 그대로이고, 금액과 일정도 그 샘플의 값이에요.
